# JARA – Run. Explore. Conquer.

JARA is a location-based running application that combines fitness tracking with territory-conquest gameplay. It turns outdoor running into a competitive experience where users can track their activities and capture geographical territories through movement.

## Core Features

- **GPS Running Tracking:** Track outdoor running activities using device location services.
- **Territory Capture:** Capture geographical territories through location-based gameplay.
- **Run Data Storage:** Store running sessions and associated application data.
- **Interactive Experience:** Combine fitness tracking with competitive geographical exploration.

## Technology Stack

- **Framework:** Flutter
- **Programming Language:** Dart
- **Location Services:** Geolocator
- **Database:** SQL-based data storage
- **Mapping:** Flutter Map
- **Development Tools:** Visual Studio Code, Android Studio and Git

## Project Status

JARA is an ongoing personal software development project. Core running functionality, GPS-based territory capture and database storage have been implemented. Additional development and refinement are ongoing.

## Getting Started

1. Clone this repository.
2. Open the project directory.
3. Run `flutter pub get`.
4. Connect an Android device or configure an emulator.
5. Run `flutter run`.

## Project Goals

- Develop a functional GPS-based running experience.
- Implement geographical territory capture.
- Integrate fitness tracking with competitive gameplay.
- Build a reliable mobile application with persistent data storage.
